## Featured Projects

### 1. AML Transaction Monitoring & Risk Analytics

**Tools:** SQL · Python · Data Analytics

A financial crime risk analytics project using synthetic customer and transaction data to explore suspicious transaction patterns, rule-based alerts, high-risk jurisdictions and KYC documentation gaps.

**Key highlights**
- Analysed transaction patterns using rule-based screening.
- Examined customer risk tiers and flagged transaction activity.
- Explored KYC documentation gaps and high-risk counterparty exposure.
- Developed a dashboard to communicate risk indicators and monitoring insights.

**Note:** The dataset is synthetic; flagged activity represents analytical indicators, not confirmed financial crime.

[View AML Project](https://github.com/meghaibef2527-bit/AML-transaction-monitering)

### 2. Banking Sector Financial Performance Analysis

**Tools:** Python · SQL · Data Visualisation

An analysis of quarterly banking-sector performance, comparing Public Sector Undertaking (PSU) and private-sector banks, with a focus on Gross Non-Performing Assets (GNPA) ratios and related banking indicators.

**Key highlights**
- Compared GNPA trends across PSU and private-sector banks.
- Examined changes in asset-quality indicators over time.
- Visualised quarterly trends to identify differences between the two banking sectors.
- Used the analysis to develop evidence-based observations about banking performance.

[View Banking Analysis Project] (https://github.com/meghaibef2527-bit/Banking-Performance-Analysis)

### 3. Multimodal Logistics Cost & Route Optimisation

**Tools:** Microsoft Excel · Supply Chain Analytics · Scenario Analysis

A logistics analytics project exploring transport-mode selection and shipment cost optimisation while considering delivery requirements and service-level constraints.

**Key highlights**
- Compared feasible logistics options and transport modes.
- Evaluated shipment costs and potential savings against road-based alternatives.
- Examined service-level agreement (SLA) feasibility.
- Used scenario analysis to support cost-conscious logistics decisions.

**Note:** The project uses synthetic data and model assumptions. Estimated savings are potential modelled savings, not realised business outcomes.

[View Logistics Project](https://github.com/meghaibef2527-bit/megham.github/tree/main/Multimodal_Logistics_Optimisation%202)
